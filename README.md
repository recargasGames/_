# RECARGASGAMES - Sistema de Recargas

## 🚀 Descripción
Sistema de recargas de juegos con verificación automática de pagos usando Pabilo.

## 📦 Tecnologías
- HTML/CSS/JavaScript (Frontend)
- Node.js (Backend)
- Vercel (Hosting)
- Pabilo API (Verificación de pagos)

## 🔧 Configuración
1. Clona el repositorio
2. Sube a Vercel
3. Configura el dominio
